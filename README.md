
# Portfolio Risk & Return Dashboard
App Link: 
https://portfolio-risk-dashboard-y95jqeeh2n7nxnkvqvnm5h.streamlit.app/

First Financial project, built using Python and Streamlit.

## Project Overview
This application analyzes historical stock portfolio
performance and investment risk.

## Features
- Historical stock price analysis
- Interactive portfolio allocation
- Portfolio return calculations
- Annualized volatility
- Maximum drawdown
- Comparison against the S&P 500 ETF (SPY)

## Technologies Used
- Python
- Pandas
- NumPy
- yfinance
- Streamlit

## Project Objectives
Apply financial engineering concepts and Python
programming to analyze investment performance
and portfolio risk.

## Future Improvements
- Portfolio optimization
- Sharpe ratio analysis
- More stocks and ETFs
- Transaction cost modeling
